# 게임 디자인

확정된 기획 결정과 그 **근거**를 남긴다. 근거 없이 바뀐 규칙은 나중에 반드시 되돌아온다.

---

## 1. 한 줄 정의

> 무너지는 지형 위에서, 각도와 파워로 서로를 맞히는 턴제 포병전.

원작 계보(Scorched Earth → 포트리스 → 건바운드)에서 가져오는 것과 버리는 것을 먼저 못 박는다.

| 가져온다 | 버린다 |
|---|---|
| 각도 + 파워 2변수 조준 | DOS 픽셀 아트, 16색 팔레트 |
| 바람 (매 턴 변화 + 드문 돌풍) | 화면 하단의 텍스트 메뉴 UI |
| 파괴 가능 지형 + 흙 붕괴 | 20종이 넘는 무기 나열 |
| 라운드 사이 상점 | 라운드 시작 시의 긴 무기 구매 대기 |
| 낙하 데미지 | 컴퓨터 AI 성격(Cyborg, Poolshark 등) — 최소 1종만 |
| 무기별로 다른 지형 변형 | 팀킬, 자폭 유머 요소 (MVP 제외) |

## 2. 재미의 구조

원작이 30년 넘게 회자되는 이유는 그래픽이 아니라 **"한 발"에 세 겹의 불확실성을 겹쳐놓은 것**이다.

1. **바람** — 대부분 조금씩 움직이고 가끔 돌풍이 부는 외부 변수. 직전 발의 학습은 남지만 그대로 반복할 수는 없다
2. **지형 변형** — 내가 판 구덩이가 상대의 엄폐물이 되고, 상대가 판 구덩이가 내 사거리를 바꾼다
3. **무기 선택** — 같은 각도라도 무기에 따라 결과가 전혀 다르다

**지형 변형이 단순 연출이 아니라 다음 턴의 계산을 바꾸는 것**이 핵심이다. 이게 없으면 그냥 확률 맞추기 게임이 된다.

여기에 하나를 더한다.

4. **붕괴** — 폭발 직후가 아니라 **몇 초에 걸쳐** 흙이 흘러내린다. 발밑이 무너져 탱크가 떨어지고, 안전했던 절벽이 사라진다

붕괴는 원작에도 있었지만(흙이 아래로 떨어짐) 즉시 처리되는 단순 규칙이었다. Talus는 이걸 **시간을 가진 물리 현상**으로 승격시켜 게임의 정체성으로 삼는다. `docs/terrain.md`.

## 3. 매치 구조

```
매치 = 라운드 N판  (기본 N=5, 선취 3승 아님. N판 전부 하고 누적 점수)
라운드 = 전원 사망 1명 남을 때까지의 턴 반복
턴 = 조준 단계 → 해결 단계 → 정착 단계
```

| 항목 | 값 | 근거 |
|---|---|---|
| 인원 | 2 ~ 6 | 6명 넘어가면 지형이 턴 한 바퀴 만에 원형을 잃는다 |
| 라운드 수 | 5 | 고정 길이 누적 점수제. Phase 3 기준선은 `docs/match.md` |
| 라운드당 예상 시간 | 2~4분 | |
| 팀 모드 | 개인전 / 2인팀 / 3인팀 | 팀전은 MVP 이후 |

**누적 점수제인 이유:** 선취 3승이면 2:0에서 3라운드가 사실상 무의미해진다. 5판 전부 치르고 킬·생존·명중 정확도를 누적하면 지고 있어도 끝까지 플레이할 이유가 남는다.

**Phase 3 기준선:** 생존자가 1명 이하이면 라운드 종료, 0명이면 전멸 무승부다.
40턴 상한에서는 최고 HP 단독 선두가 승리한다. 점수·경제 계수와 공동 선두 처리는
`docs/match.md` §6에 있고, 수치는 아직 밸런싱 대상이다.

## 4. 턴 구조 — 한 발의 원인과 결과

### 4.1 확정: 완전 순차 턴

Phase 3.5 직접 플레이에서 동시 발사는 화면은 화려하지만 **내가 쏜 한 발의 긴장, 착탄의 원인,
그 한 발로 지형이 바뀌는 결과**를 모두 흐린다는 것이 확인됐다. 원작 계보의 핵심 감정은
"한 발을 모두가 숨죽여 지켜보는 시간"이다. 표준 규칙을 순차 턴으로 되돌린다.

```
[현재 플레이어 조준] 각도/파워/무기/이동/아이템 입력
       ↓ 확정 또는 제한시간 종료
[비행]               현재 플레이어의 포탄만 날아감
       ↓ 마지막 자탄 착탄
[폭발·정착]          피해 → 카빙/적층 → 붕괴 정착 → 탱크 재배치
       ↓ 결과가 완전히 확정
[다음 생존 플레이어]
```

- 턴 순서는 슬롯 오름차순 순환이며 사망한 슬롯은 건너뛴다.
- 라운드 1은 슬롯 0이 시작하고, 다음 라운드는 시작 슬롯을 하나씩 순환한다.
- `turnNo`와 `roundTurn`은 **발사 한 번마다** 증가한다.
- 앞 플레이어가 만든 구덩이와 붕괴가 완전히 반영된 뒤 다음 플레이어가 조준한다.

| 얻는 것 | 설명 |
|---|---|
| 긴장 | 한 발의 체공 시간을 전원이 함께 본다 |
| 인과관계 | 누가 어떤 지형 변화를 만들었는지 즉시 읽힌다 |
| 전술 변화 | 방금 무너진 지형을 보고 다음 플레이어가 새로 조준한다 |
| 고전 포병 감성 | 발사권 자체가 사건이 되고, 상대 턴을 관전하는 재미가 생긴다 |

### 4.2 감수하는 것

6인전은 자기 턴까지 기다리는 시간이 길다. 이 문제는 동시 해결로 핵심 감정을 없애지 않고,
Phase 4에서 조준 제한시간·관전 정보·AI 입력 지연을 줄이는 방식으로 다룬다.

### 4.3 기각한 대안

| 대안 | 기각 사유 |
|---|---|
| **동시 조준 + 동시 해결** | 직접 플레이에서 한 발의 긴장과 지형 변화의 인과가 사라졌다 |
| **동시 조준 + 순차 해결** | 뒤에 해결되는 포탄은 이미 사라진 지형을 기준으로 조준한 것이 되어 불공정하다 |
| **실시간 (턴 없음)** | 조준 시간이 재미의 원천인데 그 축을 없앤다 |
| **비동기 (하루 1턴)** | 붕괴 연출을 함께 지켜보는 가치가 사라진다 |

### 4.4 조준 단계 제한시간

| 항목 | 값 | 근거 |
|---|---|---|
| 기본 | 20초 | |
| 현재 플레이어 확정 시 | 즉시 진행 | 입력을 끝냈는데 타이머를 기다리지 않는다 |
| 미입력 시 | **직전 턴 값으로 자동 발사** | 아무것도 안 하는 것보다 낫다. 연결 끊김에도 판이 진행된다 |
| 각 플레이어의 첫 발 | 30초 | 지형과 조작을 처음 읽는 발이라 더 준다 |

## 5. 조준

| 변수 | 범위 | 단위 |
|---|---|---|
| 각도 | 0 ~ 180 | 0.5° 단위 (내부는 정수 데시도 = 각도×10) |
| 파워 | 0 ~ 1000 | 1 단위 |

**입력 방식은 3가지를 전부 지원한다.** 빠른 마우스 조작과 정밀한 키보드·직접 입력을 함께 둔다.

- **마우스 조준** — 전장을 클릭하거나 드래그하면 포신 각도, 휠은 파워를 조절한다. Shift+휠은 미세 조정
- **키보드** — ←/→ 각도, ↑/↓ 파워. `Space`를 누르는 동안 파워가 차고 떼는 순간 발사한다. Shift 조합으로 미세 조정
- **목표 파워 핀** — 전장 하단의 긴 충전 바를 클릭/드래그해 5단위 기준점을 놓는다. 충전이 핀에 닿으면 강조되며 자동 발사는 하지 않는다
- **직접 입력** — 각도/파워 숫자 필드. 고수용

### 5.1 조준 보조 — 어디까지 허용할 것인가

| 기능 | 허용 | 근거 |
|---|---|---|
| **직전 내 포탄의 궤적 잔상** | ✅ | 원작에서도 종이에 적던 걸 화면이 대신해줄 뿐. 이게 없으면 신규 유저가 첫 3턴을 버리게 된다 |
| 궤적 잔상에 사용한 각도/파워 라벨 | ✅ | 위와 동일 |
| 남의 포탄 궤적 잔상 | ✅ (색 구분) | 관전 재미. 지형이 변하므로 그대로 베껴도 안 맞는다 |
| **실시간 예상 궤적선** | ❌ | 이걸 켜는 순간 게임이 "선 맞추기"가 되고 바람·조준의 의미가 전부 증발한다 |
| 사거리 원 표시 | ❌ | 위와 동일 |
| 각도/파워 기억 (무기별) | ✅ | 편의 기능. 실력에 영향 없음 |

**예상 궤적선은 절대 넣지 않는다.** 이 게임의 스킬 전부가 여기에 걸려 있다.

## 6. 무기

**무기 설계 원칙: 모든 무기는 지형을 다르게 바꾼다.** 데미지만 다른 무기는 넣지 않는다.

원작 무기 고유명은 쓰지 않는다. 아래는 자체 명명.

### 6.1 MVP 8종

| 무기 | 지형 효과 | 역할 | 탄약 |
|---|---|---|---|
| **표준탄** | 작은 원형 구덩이 | 기본. 무한 | ∞ |
| **파쇄탄** | 큰 원형 구덩이 + 넓은 붕괴 유발 | 지형을 크게 바꾸는 용도 | 유한 |
| **분열탄** | 정점에서 5발로 갈라져 넓게 산개 | 대략적 위치만 알 때 | 유한 |
| **굴착탄** | 지면에 박힌 뒤 **아래로** 파고들며 폭발 | 언덕 뒤 은폐물 제거 | 유한 |
| **전복탄** | 착탄 후 **경사를 따라 굴러가서** 폭발 | 구덩이 안에 숨은 적. 모래 경사와 직접 상호작용 | 유한 |
| **성형탄** | 데미지 높고 구덩이는 아주 작음 | 지형을 **보존**하고 싶을 때 | 유한 |
| **적층탄** | 폭발 대신 **흙을 쌓는다** | 방어벽 건설. 유일한 지형 추가 무기 | 유한 |
| **핵포탄** | 반경 80셀의 초대형 구덩이와 광역 충격 | 돈을 오래 모아 한 번 쓰는 후반 최종 병기 | 상점 전용, 초기 0발 |

**전복탄과 적층탄이 이 게임의 정체성이다.**
전복탄은 모래 경사가 물리적으로 존재해야만 성립하는 무기다. 적층탄은 파괴 일변도인 원작 계보에 없던 축을 만든다.
핵포탄은 기반암과 맵 전체를 지우지 않고, 검증된 최대 카빙 반경 80셀 안에서만 전장을 크게 뒤엎는다.

### 6.2 비-포탄 아이템

| 아이템 | 효과 |
|---|---|
| **차폐막** | 1회 피격 무효. 사용 시 소모 |
| **낙하산** | 낙하 데미지 무효. 지형이 무너져 떨어질 때 자동 발동 |
| **연료** | 턴당 좌우로 조금 이동. 이동력은 지형 경사에 제한받음 |
| **측풍계** | 다음 턴 바람값과 돌풍 여부를 미리 표시 |

### 6.3 기각

| 대안 | 기각 사유 |
|---|---|
| 원작 수준의 무기 20종 | 선택지가 과도하다. 8종으로 시작해 플레이 데이터를 보고 늘린다 |
| 맵 전체 초기화급 핵무기 | 지형 서사가 사라진다. 실제 핵포탄은 카빙 반경을 80셀로 제한한다 |
| 유도 미사일 | 조준 스킬을 무의미하게 만든다 |
| 소이탄/화염 확산 | 재밌지만 지형 자동자에 새로운 상태(불타는 셀)를 추가해야 한다. Phase 4 이후 |

## 7. 경제

| 항목 | 값 |
|---|---|
| 시작 자금 | 라운드 1 시작 시 지급 |
| 획득 | 명중 데미지 비례 + 킬 보너스 + 라운드 생존 보너스 |
| 상점 | 라운드 **사이**에만 열림. 30초 제한 |
| 이월 | 다음 라운드로 이월됨 |
| 탄약 이월 | 이월됨 |

Phase 3 프로토타입 기준선은 시작 자금 1500, 피해 1당 8골드, 킬 400골드, 생존 300골드다.
첫 상점은 라운드 1 종료 뒤 열린다. **이 시점과 수치는 최종 확정이 아니며** `decisions.md` C6와
`docs/match.md` §2를 따른다.

핵포탄은 `4,800G`로 시작 자금만으로 살 수 없고, 통상 세 라운드가량 수입을 모아 한 발을 구매한다.

**꼴찌 보정을 넣는다.** 하위 순위에게 자금 보너스. 근거: 5라운드 중 2라운드에서 이미 격차가 벌어지면 남은 3라운드를 아무도 안 한다. 보정 계수는 미결.

**상점을 라운드 중에 열지 않는 이유:** 동시 턴 구조에서 상점까지 동시에 열면 조준 단계가 인지적으로 과부하된다. 조준 단계는 조준만 한다.

## 8. 탱크와 피해

| 항목 | 값 | 근거 |
|---|---|---|
| HP | 100 | 원작과 동일. 즉사가 아닌 이유는 아래 |
| 피해 계산 | 폭발 중심에서의 거리로 선형 감쇠 | 근접 판정이 명확해야 조준 실력이 보상받는다 |
| 낙하 데미지 | 낙하 거리 비례 | **붕괴 메카닉의 핵심.** 이게 없으면 지형이 무너져도 손해가 없다 |
| 매몰 | 흙에 완전히 파묻히면 턴당 지속 피해 | 적층탄에 목적을 준다 |
| 화면 밖 이탈 | 즉사 | |

**즉사가 아닌 이유:** 즉사면 동시 턴 구조에서 첫 턴에 운 좋게 맞은 사람이 아무것도 못 하고 나간다. HP가 있어야 6인 동시 사격이 성립한다.

### 8.1 탱크는 지형에 얹혀 있다

탱크는 **지형 위에 놓인 물체**이며, 지형이 변하면 반드시 재배치된다.

- 발밑 흙이 사라지면 떨어진다 (낙하 데미지)
- 경사가 안식각을 넘으면 흙과 함께 **미끄러진다**
- 흙이 위에 쌓이면 매몰된다
- 정착 단계가 끝난 뒤 최종 위치와 각도(포신 기준선)가 확정된다
- 차체는 좌우 궤도 아래의 지표를 따라 최대 `±14°` 기울어진다
- 반원형 각도계와 포신의 기준선도 차체 기울기를 따르고, 입력 각도는 그 기준선에서 잰 상대각이다

**실제 발사각도 차체 경사를 반영한다.** 화면에 보이는 포신과 포탄 궤적이 다르면 조준 피드백을
믿을 수 없기 때문이다. 같은 지형에서는 경사가 결정론적으로 동일하므로 학습 가능성도 유지된다.

## 9. 바람

| 항목 | 값 | 근거 |
|---|---|---|
| 변경 주기 | **90%는 `-1/0/+1`, 10%는 `±3` 돌풍** | 평상시 학습은 보존하고 가끔 판을 흔든다 |
| 표시 | 화면 상단 방향 게이지 + 현재 숫자 + 배경 먼지 | 수치와 분위기를 함께 읽는다 |
| 다음 턴 예보 | 측풍계 아이템 | 돌풍에 대비할 경제 선택지를 만든다 |
| 세기 범위 | `-4 ~ +4` | 강풍이 실제 조준 변수가 되되 중력 절반 값 6은 피한다 |

**바람은 수평 등가속도로만 적용한다.** 난류나 고도별 풍속은 넣지 않는다. 예측 불가능한 게 아니라 배울 수 있는 변수여야 한다.
첫 턴도 같은 규칙으로 0에서 시작한다. 범위 끝에서는 넘은 만큼 안쪽으로 반사하며, 돌풍 턴에는
상단 수치와 색을 강조해 갑작스러운 변화가 버그가 아니라 사건으로 읽히게 한다.

## 10. 맵

| 항목 | 값 |
|---|---|
| 크기 | 1920 × 1080 px (셀 그리드 960 × 540) |
| 생성 | 시드 기반 절차적 생성 |
| 스폰 | 지표면 위, 최소 간격 보장 |
| 화면 | 전체 맵이 한 화면에 들어옴 (스크롤 없음) |

**스크롤을 넣지 않는 이유:** 동시 턴에서 6명의 포탄이 동시에 날아가는데 카메라가 하나면 뭔가는 반드시 화면 밖에서 벌어진다. 맵 전체가 항상 보이는 게 유일하게 공정한 답이다. 대신 착탄 순간에만 짧게 줌인한다.

### 10.1 지형 생성

절차적 생성은 **재미있는 지형**을 만들어야 하며, 자연스러운 지형이 목표가 아니다.

| 요소 | 목적 |
|---|---|
| 봉우리와 계곡 | 직사와 곡사의 선택지 |
| **오버행 / 아치** | 모래 자동자가 있어야만 가능한 구조. 무너뜨리는 재미 |
| 기반암 기둥 | 절대 안 부서지는 앵커. 후반에도 맵이 완전 평지가 되지 않게 고정 |
| 모래 주머니 | 기반암 위에 얹힌 대량의 모래. 건드리면 크게 무너진다 |

**기반암 앵커가 없으면 5라운드째에는 모든 맵이 평평한 언덕 하나가 된다.** 생성기는 반드시 기반암 골격을 먼저 그리고 그 위에 흙을 덮는다.

## 11. AI

MVP에 1종만 넣는다. 사람이 안 모일 때 방을 채우는 용도.

- 마지막 관측 위치 + 바람을 반영한 탄도 역산에 오차를 더해 쏜다
- 난이도 = 오차 크기
- **지형을 이용하는 AI는 만들지 않는다.** 비용 대비 효과가 없다
